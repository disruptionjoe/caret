# Caret^ Manifesto

Caret^ exists because agent workflows got bloated.

Too many systems try to solve clarity by adding more ceremony.
More framework.
More prompt.
More prose.
More scaffolding wrapped around simple intent.

Caret^ goes the other direction.

Small marks.
Hard edges.
Clear intent.

## We Believe

Intent should be lighter than implementation.

You should be able to signal pressure, stance, scope, separation, and operating mode without dragging a whole procedural novel behind it.

You should not need a giant framework to say:

- review this harder
- use a sharper lens
- split the worker
- reset the context

That is what Caret^ is for.

## We Refuse

We refuse prompt sprawl dressed up as sophistication.

We refuse the idea that every workflow improvement needs a new mini-language.

We refuse hidden magic.
Hidden closers.
Hidden precedence.
Hidden trust assumptions.

If a notation system gets stronger by getting murkier, it is not stronger.

## We Want

We want a notation layer that stays small enough to carry in your head.

We want structure to be fixed where it matters and vocabulary to stay open where reality keeps changing.

We want Markdown to stay useful.
Harnesses to stay free to implement.
Trust boundaries to stay explicit.

We want something you can:

- paste into a chat
- load into a platform skill
- mount into a harness
- teach in minutes
- extend without breaking the core

## The Standard

Caret^ should earn every symbol it asks you to learn.

If the mark does not create real clarity, cut it.

If the example drifts from canon, fix it.

If the repo grows outward from the cheatsheet but stops serving the cheatsheet, trim it back.

If prose is doing the job better, let prose win.

This is not a religion against words.
It is a refusal to waste them.

## The Shape

The core stays tight.

- `^` directs
- `^^` changes the hat
- `^^^` changes the worker
- `^^^^` cuts a fresh-eyes boundary

Everything else has to justify itself.

## The Promise

Caret^ will stay portable.

It will stay smaller than the systems around it.

It will stay honest about what it is:
not an execution engine,
not a hidden runtime,
not a replacement for judgment.

It is a semantic signal layer.

That is enough.

That is the power.
