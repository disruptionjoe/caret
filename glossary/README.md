# Glossary

The cheatsheet stays lean.

This directory carries the surrounding vocabulary so the notation can stay sharp without forcing every definition into the product artifact.

Read order:

1. `CANON.md`
2. `FRAGMENTED.md`
3. `EMERGING.md`

Working split:

- `CANON.md` holds terms this repo treats as stable.
- `FRAGMENTED.md` holds terms people use constantly but do not mean consistently.
- `EMERGING.md` holds useful working terms that are not canon yet.

If a glossary note conflicts with `/notation/`, the notation docs win.
