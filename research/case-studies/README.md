# Case Studies

Real-world evidence of Caret^ in use.

## What belongs here

- Before/after comparisons of instruction files converted to Caret^ notation
- Token usage measurements (with vs. without notation)
- Determinism or quality comparisons
- Practitioner experience reports

## Format

Each case study should include:
- What was converted or tested
- The before state (how it was done without notation)
- The after state (with Caret^ notation)
- Measurable outcomes where possible (token count, error rate, clarity score)
