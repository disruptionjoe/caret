# Research

Research is evidence, not authority.

This directory holds the experiments, comparisons, source notes, and test bundles that support decisions elsewhere in the repo.

If research conflicts with the canon, the canon wins until the canon is deliberately updated.

## What Lives Here

- `reports/`: experiment bundles, test runs, round summaries, external comparisons
- `landscape/`: broader surrounding context
- `case-studies/`: applied conversions and deeper examples

## Placement Rule

If a file is answering:

- "what did we test?"
- "what happened?"
- "what did we learn?"
- "what external sample changed our view?"

it belongs here.

If a file is answering:

- "what rule must future contributors follow?"

it belongs in `/governance/`.
