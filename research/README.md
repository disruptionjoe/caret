# Research

Evidence that the notation works.

Contributions here should be comparisons: using Caret^ notation vs. not. Structured evidence that the notation improves clarity, reduces token usage, or produces better agent behavior.

The bar: if it does not show a measurable or observable difference, it is not research. It is an opinion.

## What a good contribution looks like

- Clear setup: what was tested, what tools were used, what the baseline was
- Side-by-side comparison: with notation vs. without
- Observable result: tokens saved, errors reduced, outputs improved, or behavior changed
- Reproducible: someone else could run the same test
