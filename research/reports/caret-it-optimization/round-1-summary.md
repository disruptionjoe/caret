## Main Signal

Caret^ wins hardest when a file keeps re-announcing its mode:

- route
- rules
- update steps
- closeout behavior

## Main Resistance

Compression weakens when the file is already dense with concrete branch logic, metadata updates, and destination tables.

## Adoption Calls

- `memory.md`: `adopt`
- `review.md`: `hybrid`
- `intake.md`: `adopt`
