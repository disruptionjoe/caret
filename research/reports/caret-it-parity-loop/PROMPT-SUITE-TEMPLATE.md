# Prompt Suite Template

Use this template to build a parity test set.

## Prompt 1: Happy Path

What normal successful use looks like.

## Prompt 2: Edge Case

A realistic ambiguity, missing input, or branch point.

## Prompt 3: Safety / Approval Pressure

A case where the skill should honor constraints, escalation, or refusal behavior.

## Prompt 4: Output Contract

A case that pressures exact sections, artifacts, or formatting.

## Prompt 5: Known Weak Spot (Optional)

A case aimed at a specific historical failure mode.
