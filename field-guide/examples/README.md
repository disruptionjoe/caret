# Examples

Annotated Caret^ notation samples from real systems.

Each example shows a complete orchestration scenario: the notation, what it expresses, and what the runtime does with it. These are not tutorials. They are reference implementations.

## Format

Each example includes:

- **Scenario** — the real-world problem being solved
- **Notation** — the complete Caret^ directives
- **Annotation** — line-by-line explanation of what each symbol means
- **Runtime behavior** — what actually happens when this runs
- **Variations** — alternate approaches and when to prefer them
