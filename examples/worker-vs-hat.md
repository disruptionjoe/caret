# Worker vs Hat

This is the split that has to stay clean.

`^^` changes the hat.
`^^^` changes the worker.

## Same Worker, New Lens

```text
^^reviewer ^depth7
  Check the draft for weak claims and missing support.
```

Meaning:

- the current worker stays active
- the worker puts on a reviewer hat
- the scoped text is handled through that lens

## New Worker, New Responsibility Boundary

```text
^^^reviewer ^depth7
  Check the draft for weak claims and missing support.
```

Meaning:

- a separate worker is requested
- responsibility shifts to that worker
- the harness decides how much context to pass

## Quick Rule

If you want a different perspective inside the same acting entity, use `^^`.

If you want a distinct worker boundary, use `^^^`.
