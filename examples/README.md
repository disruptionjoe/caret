# Examples

Examples are where the notation gets stress-tested.

They are not canon. They are demonstrations, edge-case probes, and working reference points.

If an example drifts from `/notation/`, the example loses.

## Why Flat

Patterns and examples can wear more than one label at once.

So the directory stays flat. Grouping lives here, not in nested folders.
