# Fresh Eyes

`^^^^` is not a worker selector.

It is a context reset boundary.

## Explicit Boundary

```text
^^^writer
  Draft the first pass.
  ^^^^
  Re-read the draft as if you have not seen it before.
  Mark anything that now feels muddy, bloated, or assumed.
  ^^^^
  Fold the strongest corrections back into the writer pass.
```

The writer worker remains the enclosing boundary. The `^^^^` section creates a fresh-eyes segment inside it.

## Boundary To End Of Block

```text
^^^writer
  Draft the first pass.
  ^^^^
  Re-read the rest of this block with prior assumptions stripped down.
```

If the boundary is not closed explicitly, it continues to the end of the containing block.

## Quick Rule

Use `^^^^` when the problem is stale context.

Use `^^` or `^^^` when the problem is lens or responsibility.
